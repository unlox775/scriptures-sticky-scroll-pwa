Fix the sticky verse/bookmark ribbon in the Scripture Reader PWA so it never drifts off-screen while sticky.

## What Dave wants
In reader mode, while scrolling (finger/wheel OR auto-scroll), the ribbon currently drifts a little off the top of the viewport and then drifts back on. Desired behavior:

1. **When the ribbon is sticky:** it should stay wedged at its topmost / tallest on-screen point. It must never leave the viewport. Think of it as pinned to a fixed top inset and following the reader wherever they are. It is always visible, implying it is following you.
2. **When the ribbon is not sticky:** it should scroll off the screen normally with its verse, like any other content.
3. **Verse-to-verse updates must keep the existing bounce/slide animation.** When the active verse changes (next verse down), the ribbon should still slide down to the next verse, roll up, then settle — the normal bounce from verse to verse. Do not flatten that into a hard jump. Only the *drift-off-screen-during-scroll* should go away.

## How to work
- Investigate how the ribbon currently works. Likely related to the sticky bookmark / reading-anchor tracking (~25% from top) in reader mode. Also look at `scroller-lab.html` and `scroller-v3-lab.html` if they are the ribbon/scroller playground.
- My guess (non-binding, verify and discard if wrong): the ribbon's Y is loosely tracking scroll/anchor instead of being clamped to stay fully visible at a stable top inset while sticky.
- Run the app (`npm install`, `npm run build:data` if needed, `npm run dev`) and reproduce the drift yourself.
- Implement the smallest correct fix. Do not rewrite the reader.
- Follow existing repo conventions (see AGENTS.md, documentation/). Playwright is already set up — add or update a test if there is a natural place for this.
- Take **before and after screenshots** of:
  - mid-scroll with sticky ribbon (after: fully on-screen at the top, not clipped)
  - verse-to-verse transition (bounce/slide still visible)
  - not-sticky ribbon (still allowed to leave the viewport)
- Open a pull request Dave can merge. Put the screenshots in the PR body and explain the behavior in plain language.

## Done when
- PR is open against the default branch.
- Sticky ribbon stays fully visible at its topmost on-screen point during manual and auto-scroll.
- Verse-to-verse bounce/slide still happens.
- Non-sticky ribbon still scrolls away.
- Screenshots in the PR prove it.
